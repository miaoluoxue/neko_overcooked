# 移动菜板切菜重定位

日志 1789711591–1592 两名厨师反复直调 use 失败“身边没有可互动的东西”，仍继续整套切菜，最终判物品未变化。切菜循环之前只用 `_board_workable` 记成功次数，无论是否可作用都继续按键。

现在目标失效时，读取最新 map 中同 id 菜板；只有板上仍是目标的可加工原料，才重走 `_approach`，随后再次以游戏交互目标判断可用。每次切菜最多重定位两次，仍不可用就停止空按。已经切好的材料和空板不会触发重定位。

依据沿用已读取的 InteractWithItemHelper.IsColliderInArc 当前碰撞面判定、ServerWorkableItem.HasFinished 的真实进度条件。没有改变切菜次数或游戏规则。

85 项回归测试通过；新增测试覆盖旧引用对应的移动菜板和已加工材料拒绝，禁用重定位后测试出现 1 个断言失败、0 个运行错误。下一局自动加载，避免中途重置厨师计划。气球关仍未通过。
